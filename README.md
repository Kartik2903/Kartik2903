A scalable marketplace for university students featuring robust RESTful APIs serving 500+ users.

- **Tech Stack:** <img src="https://skillicons.dev/icons?i=nodejs,postgres,react&theme=dark" height="20" align="center"/> Node.js, PostgreSQL, RAG Pipeline, React Native, WebSockets
